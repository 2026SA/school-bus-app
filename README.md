# スクールバス乗車管理 PWA（試作版）

平日の下校便に絞った操作試作です。実在データは使用していません。

## デモ用アカウント
- 児童・生徒：`S001 / A1B2`
- 保護者：`P001 / P1A1`
- 一般教員：`T001 / T1E1`
- 管理者：`A001 / A1D1`

ログイン画面のボタンから直接入ることもできます。

## 入っている機能
- 4路線共通：13:30 / 15:10 / 16:30 / 18:00
- 児童生徒・保護者・一般教員・管理者の権限分離
- 「乗らない」を含む乗車予定登録
- 曜日ごとの繰り返し設定と約1か月への反映
- 単日の例外変更
- 変更理由・備考・変更履歴
- 8:40未申告リマインド（画面内通知の試作）
- 8:50以降の本人・保護者による当日変更ロック
- 一般教員による締切後変更
- 13:30 / 15:10 / 16:30便の乗車確認
- 18:00便は乗車確認対象外
- 保護者画面で乗車確認を閲覧
- 教育委員会用PDFのプレビュー／印刷
- 教育委員会への「送信」操作の模擬
- 管理者による当日運行便ON/OFF
- 玄関ディスプレイ：時刻ごとに5秒で自動切替
- PWA manifest / service worker

## デモ時刻
実際の時刻に関係なくテストできるよう、画面上部で時刻を切り替えられます。
`08:35 / 08:45 / 09:10 / 13:20 / 15:00 / 16:20 / 17:50`

## 起動
`index.html` を直接開いても大半の機能は試せます。
ホーム画面追加まで確認するには、HTTPS または localhost が必要です。
GitHub Pages にこのフォルダの中身を置けばPWAとして確認できます。

ローカルPCで試す場合：

    python -m http.server 8000

その後 `http://localhost:8000/` を開きます。

## 本番化で必要になるもの
この試作は画面と業務フロー確認用で、データはブラウザの localStorage にのみ保存されます。本番では共有バックエンドが必要です。
想定：認証、共有DB、Web Push、PDFサーバー生成、実メール送信、1年後削除、監査ログ、PIN失敗回数制限、権限管理、HTTPS/セキュリティルール。
