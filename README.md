# スクールバス乗車管理 PWA v0.6 試作

## デモアカウント
- 児童・生徒: S001 / A1B2
- 保護者: P001 / P1A1
- 先生: T001 / T1E1
- 管理者: A001 / A1D1

## v0.6で追加・変更した主な機能
- 「一般教員」を「先生」に変更
- 乗車確認を「選択 → 確定」方式へ変更
- 路線ごとの全員選択／全員解除
- 時刻全体の全員選択／全員解除
- QR受付専用画面
- 8:50以降は受付終了表示 → 本日の運行案内へ自動切替
- 運行案内は5秒ごとに便を切替
- 出発10分前／5分前の強調表示
- QR受付案内画面は氏名を表示せず人数のみ
- 管理者画面で路線・停留所・時刻・定員・締切時刻を編集
- 管理者3名の試作アカウント
- 先生のID/PIN/QRトークン表示
- 全児童生徒のID/PIN/QRトークン表示
- 本人・保護者から路線・降車場所を変更可能
- バス通学者／一般利用者を区別
- 一般利用者の定員判定（低学年優先、同学年は申込が早い順）
- 満席時の利用不可表示
- ID/PIN通知書文面の管理者編集・プレビュー
- 年度更新／転入転出の操作ボタン（試作表示）

## QRについて
この試作では実QR画像ではなく「QRトークン」を使って動作確認します。
本番化ではランダムトークンを実際のQRコードに変換します。

## データについて
すべてブラウザの localStorage に保存されます。実在の個人情報は入力しないでください。
本番化では Firebase / Firestore へ移行する想定です。

## GitHub Pages更新
既存の school-bus-app リポジトリに、以下を上書きしてください。
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png

更新後は古いService Workerが残る場合があるため、公開URLに `?v=04` を付けて開くか、サイトデータを削除してください。


## v0.6 追加機能：QRコード入りPDF
- 管理者 → アカウント管理 → 各児童生徒の「通知書PDF」
- 全家庭分のID・PIN通知書を一括印刷／PDF保存
- 児童生徒QRカードを一括印刷／PDF保存
- 先生用ID・PIN・QR通知書を個別／一括印刷
- QRコードは外部サービスへ送信せず、同梱の `qrcode-local.js` でブラウザ内生成

PDFはブラウザの印刷画面で「PDFに保存」を選んでください。

- 先生用通知書は1人1ページのまま
